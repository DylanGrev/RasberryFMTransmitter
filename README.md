## Projectgegevens
Naam van het project: Rasberry FM Transmitter en Transistor Radio (keuzedeel)

Ik wil graag leren hoe ik een app kan maken voor de Raspberry Pi en hoe ik audio kan uitzenden via de FM-band. Hiervoor wil ik een UI maken waarmee ik gemakkelijk drie audio-inputs kan combineren tot één output. Denk hierbij aan twee platenspelers en één microfoon die samen naar één zender gaan.
Het is de bedoeling om audio uit te zenden op een FM-frequentie die zo min mogelijk in gebruik is. Dit wil ik doen met een Raspberry Pi, omdat deze met de juiste hardware gebruikt kan worden om FM-signalen uit te zenden. De geluidskwaliteit is misschien niet de beste, maar het belangrijkste is dat het werkt.
Ik wil leren hoe het uitzenden van audio via FM met een Raspberry Pi werkt en hoe ik hiervoor een app kan ontwikkelen. Daarnaast wil ik zelf een radio maken waarmee ik kan testen of de zender goed werkt. Op deze manier kan ik mijn kennis en vaardigheden uitbreiden voor het keuzedeel Programmeren van Microcontrollers.


De reden(en) waarom je dit project wilt maken:
ik ben zelf erg fan van de piraten/geheime zenders en veel van die mensen maken ook nog gebruik van oud matteriaal en ik dacht van hoe zou ik dit ook kunnen moderniseren.

Beschrijving van de randvoorwaarden:
• er moet een UI in komen voor de gebruiker die makkelijk te brijpen is (mooi hoeft persee niet).
• Je moet alle 3 de inputs kunnen instellen met hoe luid en een mute/unmute functie.
• Een invulbaar tekst veld waar je tekst kan maken die dan op de radio te zien is zoals de naam van de zender.
• het moet zenbaar kunnen zijn via de rasberry PI
• ik zou het moeten op kunnen vangen met een FM radio'tje de radio moet ook zelf gemaakt worden

Denk aan AVG, Copyright, Licenties, Wettelijke impact, Maatschappelijke impact
• Telecommunicatiewet
	• Korte uitleg: Bepaalt dat de ether van de staat is en verbiedt het zenden zonder officiële vergunning.
• Mediawet 2008
	• Korte uitleg: Bepaalt dat je toestemming moet hebben om programma's uit te zenden voor het publiek.
• Regeling gebruik van frequentieruimte zonder vergunning en zonder meldingsplicht 2015
	• Korte uitleg: Regelt de uitzondering voor mini-FM-zendertjes (zoals voor in de auto) met een heel klein bereik.

Dit gaat over een FM transmitter die je bij de action kan kopen voor in je auto dan is het wel legaal.
• 100% legaal: Voldoet aan de wet mits gekocht in de winkel (met CE-keurmerk).
• Extreem laag vermogen: Maximaal 50 nanowatt, genoeg voor jouw auto maar stoort anderen niet.
• Geen vergunning nodig: Valt onder de vrijstellingsregeling; je hoeft niets aan te vragen.
• Zelf lege frequentie zoeken: Je mag officiële radiozenders niet storen; zet hem op een vrije frequentie.
Als ik alles kan instellen over hoe en wat zoals de FM transmitter op de rasberry dan kan ik dit binnen de regels maken en gebruiken als prive.
